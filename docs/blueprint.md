# **App Name**: CryptoLens

## Core Features:

- Intelligent Token Analysis: An AI-powered tool that evaluates token fundamentals, sentiment, and project whitepapers using LLMs for deep insights.
- Live Market Dashboard: Real-time pricing data and metadata for thousands of tokens powered by the CoinGecko API.
- TradingView Chart Suite: Advanced technical analysis integration featuring professional-grade interactive charts.
- Whale Wallet Stream: A live visual feed monitoring large on-chain transactions to track significant institutional movements.
- Sentiment Pulse Engine: A dashboard displaying aggregate fear and greed index scores and market social sentiment visualization.
- Crypto Academy Modules: A curated collection of educational content and micro-learning units for blockchain mastery.

## Style Guidelines:

- Primary color: High-tech Deep Azure (#4785FF) evoking a sense of data precision and institutional trust.
- Background color: Deep Midnight Charcoal (#0E1116), a heavily desaturated blue that reduces eye strain for long analytical sessions.
- Accent color: Vibrant Electric Cyan (#1CD4EC) for high-contrast highlights on gains and primary calls to action.
- Headline font: 'Space Grotesk' (sans-serif) for a computerized, scientific feel. Body font: 'Inter' (sans-serif) for maximum legibility of dense financial data.
- Code font: 'Source Code Pro' (monospace) for displaying wallet addresses, transaction hashes, and smart contract snippets.
- Pixel-perfect, thin-line geometric icons that match the precision of technical charts.
- Smooth layout transitions and subtle pulsing glow effects for live price updates to mimic a high-frequency trading terminal.
